async function fetchData() { try { // RESET data agar tidak menumpuk saat refresh/load dataSupp = []; dataCust = []; // 1. Ambil Data PO Supplier const { data: resSupp } = await _supabase.from('purchase_orders').select('*'); if (resSupp && resSupp.length > 0) { dataSupp = resSupp.map(item => ({ po: item.po_code, tgl: item.tgl_po, nopo: item.no_po, tujuan: item.tujuan, qtyOrig: item.qty })); } // 2. Ambil Data PO Customer const { data: resCust } = await _supabase.from('customer_po').select('*'); if (resCust && resCust.length > 0) { dataCust = resCust.map(item => ({ name: item.delivery_to, tgl: item.po_date, nopo: item.number, qty: item.jumlah, del: 0, supp: '', tujuanCust: '', tglKirim: '' })); } // 3. Ambil data pengiriman dan gabungkan ke dataCust await fetchPengiriman(); // Pastikan minimal ada 1 baris kosong jika database benar-benar kosong if (dataSupp.length === 0) dataSupp = [{ po: '', tgl: '', nopo: '', tujuan: '', qtyOrig: 0 }]; if (dataCust.length === 0) dataCust = [{ name: '', tgl: '', nopo: '', qty: 0, del: 0, supp: '', tujuanCust: '', tglKirim: '' }]; renderSupp(); renderCust(); } catch (error) { console.error("Fetch Error:", error); } } async function fetchPengiriman() { try { const now = new Date(); const firstDay = new Date(now.getFullYear(), now.getMonth(), 1).toISOString(); const lastDay = new Date(now.getFullYear(), now.getMonth() + 1, 0, 23, 59, 59).toISOString(); const { data: kirimData, error } = await _supabase .from('data_pengiriman') .select('jumlah_keluar, supplier, delivery_to, created_at') .gte('created_at', firstDay) .lte('created_at', lastDay); if (error) throw error; if (kirimData && kirimData.length > 0) { const filterWords = ['petro', 'pan', 'transport']; const filtered = kirimData.filter(item => { const targetString = `${item.supplier} ${item.delivery_to}`.toLowerCase(); return !filterWords.some(word => targetString.includes(word)); }); // Gabungkan data pengiriman ke baris dataCust yang sudah ada atau buat baru filtered.forEach((item, index) => { if (!dataCust[index]) { dataCust.push({ name: '', tgl: '', nopo: '', qty: 0, del: 0, supp: '', tujuanCust: '', tglKirim: '' }); } dataCust[index].del = item.jumlah_keluar || 0; dataCust[index].supp = item.supplier || ''; dataCust[index].tujuanCust = item.delivery_to || ''; const d = new Date(item.created_at); dataCust[index].tglKirim = `${String(d.getDate()).padStart(2,'0')}/${String(d.getMonth()+1).padStart(2,'0')}/${d.getFullYear()}`; }); } } catch (e) { console.error("Gagal tarik pengiriman:", e.message); } }
